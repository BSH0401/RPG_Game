# 게임 기획서: 《달빛 우체국》

> 밤마다 달라지는 섬을 탐험하며 편지를 배달하고, 편지에 담긴 사연을 통해 섬 주민들과 마을의 비밀을 밝혀가는 **싱글 플레이 2D 액션 RPG**.

## 핵심 순환

> 마을에서 편지와 의뢰 받기 → 밤의 섬 탐험 → 전투와 선택 → 편지 배달 → 주민과 마을 변화 확인

## 기본 정보

| 항목 | 기획 |
|---|---|
| 장르 | 싱글 플레이 2D 액션 RPG |
| 플랫폼 | PC 우선 |
| 엔진 | Unity |
| 시점 | 탑다운 2D |
| 플레이 시간 | 메인 스토리 6~8시간 |
| 개발 규모 | 1인 개발, 소규모 제작 |
| 아트 방향 | 제한된 색상 팔레트의 픽셀 아트 |
| 핵심 키워드 | 편지, 밤의 섬, 선택, 마을의 변화 |

## 주요 시스템

- **편지 배달**: 편지마다 짧은 사연과 탐험 목표. 단서로 받는 사람을 추리하고, 배달 시 작은 선택(읽기·감추기 등)을 한다. 정답·오답 없이 결과가 마을에 반영된다.
- **밤의 섬 탐험**: 마을 1곳 + 탐험 지역 3곳(숲길, 해안, 폐역, 등대 주변 중). 수작업 지역에서 출구·이벤트 위치만 밤마다 바꾼다.
- **전투**: 기본 공격, 회피, 편지 도구 스킬 1개, 적 공격 예고. 일반 적 3종, 보스 2종.
- **성장**: 경험치 대신 장비·도구(체력/회피 장비, 도구 부품, 열쇠·등불). 배달과 탐험에서 획득.
- **우체국과 마을**: 의뢰 확인, 지도와 단서, 배달 결과에 따른 외형·기능 변화.

## 콘텐츠 범위 (첫 버전)

마을 1 · 탐험 지역 3 · 주요 주민 6 · 편지 12 · 일반 적 3 · 보스 2 · 장비·도구 6 내외 · 엔딩 2 · 6~8시간

## 조작

| 입력 | 동작 |
|---|---|
| WASD / 방향키 | 이동 |
| 마우스 왼쪽 버튼 | 공격 |
| Space | 회피 |
| E | 조사·대화·배달 |
| Q | 편지 도구 사용 |
| Tab | 지도와 의뢰 확인 |

## 제작 순서

1. 핵심 플레이 샘플: 이동, 조사, 편지 수령, 목적지 도착, 배달 완료
2. 전투 샘플: 공격·회피, 적 1종, 피격과 회복
3. 작은 완성 구역: 마을 일부와 탐험 지역 하나
4. 스토리 수직 단면: 편지 3통, 주민 2명, 보스 1종
5. 나머지 콘텐츠 제작
6. 마무리: 저장, 접근성, 밸런스, 사운드, 버그 수정

## 제작 리스크와 대응

- 스토리·대사량 증가 → 주민·의뢰 수를 먼저 고정
- 전투와 탐험 분리 → 편지 도구·장비를 두 시스템에 함께 사용
- 밤마다 바뀌는 맵 → 절차 생성 대신 수작업 지역 + 소수의 변경 요소
- 픽셀 아트 제작 기간 → 애니메이션 프레임 수 제한, 팔레트 통일

## 첫 프로토타입 성공 기준 (10~15분)

- 우체국에서 편지를 받는다.
- 지도에서 목적지를 확인한다.
- 탐험 중 단서를 찾고 적과 마주친다.
- 짧은 전투를 거쳐 목적지에 도착한다.
- 편지를 전달하고, 마을이나 주민의 변화를 확인한다.

재미가 약하다면 콘텐츠를 늘리기 전에 **탐험의 발견감, 편지의 궁금증, 배달 결과의 보상감**부터 다듬는다.
